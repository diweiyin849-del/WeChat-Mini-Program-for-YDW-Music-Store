# 乐器养护参考资料

2026-10-11 核验。项目为简短原创摘要及谨慎日常建议，具体型号说明书优先；没有统一湿度、清洗周期、清洁剂或售后承诺。

- 钢琴：[Yamaha 家庭养护](https://www.yamaha.com/en/musical_instrument_guide/piano/maintenance/)，支持软布清洁、防液体、避免阳光和专业调律建议。
- 电钢琴：[Yamaha 养护](https://hub.europe.yamaha.com/articles/care-and-maintenance-of-a-digital-piano-and-keyboard)、[P-S500 官方说明书](https://vn.yamaha.com/files/download/other_assets/7/1371907/P-S500_owners_manual_En_C0.pdf)，引用表面清洁、避免喷液和断电；不推荐跨型号通用清洁药剂。
- 吉他：[Taylor 清洁指导](https://www.taylorguitars.com/support/maintenance/properly-cleaning-your-guitar)，不同表面处理清洁方式不同。不照搬品牌专用打蜡、钢丝绒处理。
- 小提琴：[Yamaha 日常养护](https://www.yamaha.com/en/musical_instrument_guide/violin/maintenance/) 和音乐事务处指南，支持干布清除松香、收纳和专业清洁。
- 古筝、竹笛、二胡：[香港康文署音乐事务处](https://www.lcsd.gov.hk/sc/mo/faq/instrumentbuyingandmaintenance.html) 中三个明确段落，支持清洁、收纳、防碰撞。不照搬统一清洗周期或自行调整建议。
- 电子鼓：[Roland 鼓垫清洁](https://support.roland.com/hc/en-us/articles/201955489-V-Drums-Cleaning-the-V-Drum-or-Cymbal-Pads)，支持清洁后干燥及谨慎选择用品；断电和稳固支架等按具体说明书执行。

收好配件、咨询琴行等为通用谨慎建议，不宣称是所有厂家的具体规定。指南保留可复制的参考链接，阅读本地内容无需联网。
