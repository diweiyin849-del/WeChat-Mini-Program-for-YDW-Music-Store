# 购物预览版隐私说明模板

本小程序展示YDW琴行乐器目录，提供购物车与费用预览，支持本机模拟订单和模拟付款，不真实扣款、不向琴行发送销售订单。

试琴预约收集联系人、电话、备注及意向时间，用于预约沟通。演示预约只保存在本机；云端预约保存在琴行云环境，仅本人和授权管理员可访问。清理本机数据不会删除云端记录，顾客可取消未结束预约。

顾客可主动开启微信确认提醒。使用微信用户标识及乐器、门店、预约时间摘要，在琴行确认后尝试发送一次；不包含电话、备注或营销消息。拒绝授权不影响预约。授权意愿及发送状态存于服务端，不宣称必然送达或已阅读。

模拟订单保存商品、金额及联系人、电话和地址快照，只存在本机，不能跨设备同步。清除历史不会恢复已扣演示库存。购物车及收货地址中用户自行填写的联系人、手机号码、详细地址保存在当前设备，无法跨设备同步。用户可以在「我的 → 清除本机购物数据」删除这些数据。

云端模式下，费用报价只接收商品规格、数量、交付方式与省市区行政编码，不接收联系人、手机号码和详细住址，不创建订单。云服务需要微信提供的用户标识用于校验管理员身份；不得把这个标识用作营销画像。

管理员填写的公开商品信息、图片及店铺资料保存在琴行配置的云环境中，管理操作记录用于追溯商品维护。

正式发布前，琴行应在微信平台与小程序中填写实际运营者信息、数据处理联系方式及真实使用的服务说明。门店资料尚未配置时，代码不会编造联系方式。这份模板不是替代平台审核的声明。



模拟订单增加期望配送/自提时间及商家确认时间，仅保存在本机，不新增消息通知；订单搜索也只查询本机记录。库存预警只在商家管理页面显示。
