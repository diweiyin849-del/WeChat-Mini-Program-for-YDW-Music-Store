# 模拟付款体验指南

本版无需商户号、密钥或支付手续费。模拟支付不会真实扣款；订单、联系人和地址只保存在当前设备，不会发送给琴行，不能跨设备同步。

## 顾客操作

1. 在微信开发者工具导入新版项目目录，保持 `miniprogram/config.js` 的 `mode: 'demo'`，点击编译。
2. 商品页点「查看费用」，或加入购物车，选择需要购买的商品后查看费用。单商品直接预览默认1件；购物车支持指定数量。
3. 选择配送地址，或选择「到店自提」并填写联系人和电话（7–15位数字，可带+号）。为方便体验，自提无需地址。
4. 选择纽约门店当地期望日期和整点时间（今天起30天内且晚于当前时间），确认有效金额后点「提交模拟订单」。如果商品改价、下架、运费改变或库存不足，页面会提示重新确认。
5. 在模拟付款页选择「模拟付款成功」「模拟付款失败」或「取消本次付款」。只有成功才扣本机演示库存；失败和退出保持待付款，可以重试。
6. 「我的 → 我的模拟订单」查看记录和详情；待付款可继续付款或取消订单。取消订单不扣库存。

## 商家操作

进入「我的 → 演示商品管理 → 管理模拟订单」。新订单已付款后先确认或调整交付时间，再标记模拟发货，再由顾客或商家确认完成；新自提订单须先确认时间再标记完成；无时间字段历史订单沿用原流程。未付款不能发货，已完成或已取消不能继续改变状态。没有真实运单、退款、退货或已付款取消功能。

## 库存、价格与清理

- 待付款不锁库存，付款时检查是否仍在售及库存是否充足。两个待付款订单争抢最后一件商品时，只能一个成功。
- 重复提交使用同一请求标识，重复付款不重复扣库存。重启后记录保留。
- 订单保存提交时名称、图片、规格、价格及地址快照。后续商品改价不改变已提交金额，付款仍检查当前库存。
- 商家编辑期间若商品或库存变化，保存会提示冲突。关闭编辑、刷新，再重新修改；旧表单不能恢复已售库存。
- 购物车付款成功只减去实际购买数量，保留后来增加的数量和未购买商品；清理失败会提示手动检查，订单仍为已付款。
- 「我的 → 清除本机购物数据」删除订单历史及其他本机购物数据，保留商品和已扣库存。需要补库存时在商品管理中手动编辑。
- 交易记录损坏时不自动恢复旧库存；先备份开发者工具本机存储并检查数据。不要将删除交易记录当作正常清理方式。

## 当前限制

cloud 模式没有模拟订单入口，直接访问模拟页面会提示不可用，不会修改云商品库存。真实微信支付尚未接入。

金额为人民币。纽约/美国是演示展示文案，地址选择与行政编码仍采用中国地区体系，配送电话仍按原11位手机号规则校验；并非真实美国地址服务。普通纽约配送0元、美国其他演示地区100元、境外200元；钢琴境内300元、境外600元不叠加；自提免费。钢琴上楼、安装、调律和保修政策仍需咨询琴行。

自动测试验证逻辑和模板条件，尚未进行微信原生编译、真机显示或实际收款验收。

订单查询、库存预警和新费率的完整步骤见 [YDW运营功能指南](ydw-operations-guide.md)。
