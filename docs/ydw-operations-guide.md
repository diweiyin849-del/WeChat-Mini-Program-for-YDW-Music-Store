# YDW琴行：新版功能使用说明

本版继续使用本机模拟订单、模拟付款和模拟配送，不会真实扣款，不会将销售订单发送给琴行。新版不需要商户号或付款密钥。

## 订单搜索和筛选

「我的 → 我的模拟订单」或「演示商品管理 → 管理模拟订单」，输入订单号、商品名称、规格或联系人，并选择全部/待付款/已付款/已发货/已完成/已取消。搜索与状态同时生效；查不到时可清空搜索和筛选。搜索读取提交时的商品快照，商品改名不会让旧订单失去原名称。

## 库存预警

「我的 → 演示商品管理」查看库存预警清单，点击「补库存」进入该商品编辑。提醒按上架商品每个规格计算，售罄独立显示；其他规格有库存不会掩盖不足。

「店铺」设置预警阈值，默认2件，剩余数量低于2才提醒；2件本身不提醒。可填0–9999，0关闭。保存配置后刷新清单；付款后重新进入管理页会显示最新库存。仅页面提示，不发短信/微信、不自动补库存。旧编辑页遇到版本冲突须关闭、刷新再修改。

## 期望交付时间与商家确认

1. 在「查看费用」选择配送或自提，填写地址或联系人。
2. 选择期望日期和整点时间，均为**纽约门店当地时间 America/New_York**，不是设备当地时间。今天起30天内（今天到第29天）、8:00–21:00且晚于当前时间。
3. 提交模拟订单并模拟付款成功。顾客详情显示「待商家确认」，此时不会锁定档期。
4. 商家进入订单详情，确认原时间或选择另一个有效时间，再点「确认交付时间（本机模拟）」。原期望已过期时必须重选。确认不重复扣库存、不清购物车、不改变付款状态。
5. 新订单确认时间后才能标记模拟发货或自提完成。顾客重新打开详情查看商家确认时间；已发货/完成/取消不能修改。

配送时间表示希望安排配送的时间，不保证国际运输的到达时间。记录仅在同一设备可见，不会通过真实微信消息通知顾客。旧订单未选择时间时显示提示，仍按原流程处理，不重写历史金额和库存。

## 境外配送演示费率

| 可选演示地区 | 普通乐器 | 钢琴（一次，不叠加） |
|---|---:|---:|
| 纽约 | ¥0 | ¥300 |
| 美国其他地区 | ¥100 | ¥300 |
| 美国以外其他可选地区 | ¥200 | ¥600 |
| 到店自提 | ¥0 | ¥0 |

后台「店铺」可修改全部费率。已提交订单保持原金额；新报价使用当前费率。金额是人民币，默认价仅用于演示，不是承运商报价。

保留原中国省/市/区县选择器：原650000编码映射为美国，650500为纽约，其他合法地区按境外演示费用计算。例如北京现在可演示配送。**没有添加全球国家城市地址库**。实际跨境税费、清关、搬运上楼、安装和调律服务需与琴行另行确认。

## YDW改名和旧数据

首页、导航、咨询、自提和后台改为YDW琴行。沿用原存储键、AppID和商品/订单标识；保留已改价格、联系方式、费率、已扣库存、收藏和历史订单快照。云端代码需重新部署才生效；展示改名不表示微信平台已审核正式名称。

只使用「我的 → 清除本机购物数据」删除本机订单历史等数据；不会恢复已扣库存。补库存请在商品管理编辑，不要通过删除交易存储键恢复品牌或库存。

微信开发者工具原生编译、真机渲染、云部署和真实物流仍需另外验收。
