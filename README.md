# YDW琴行微信小程序

YDW琴行是一个微信原生乐器商城演示项目，包含商品浏览、购物车、收藏对比、试琴预约、订单管理和商家库存管理，适合在微信开发者工具中体验完整的选购流程。

**当前默认使用本机演示模式：模拟付款不会真实扣款，销售订单不会发送给琴行，也不能跨设备同步。** 云端预约与确认提醒代码已提供，实际使用需要另外配置账号并部署。

## 功能介绍

- **乐器目录**：钢琴、电钢琴、吉他、古筝、小提琴、笛子、二胡、电子鼓，共40款演示型号及40张本地示意图。
- **选购工具**：商品搜索、分类、价格排序、价格区间和库存筛选、收藏、最多3款商品对比。
- **模拟订单**：购物车、地址、配送/自提费用、模拟付款成功/失败/取消、订单搜索及状态筛选。
- **库存管理**：付款成功后只扣一次库存，商品版本冲突保护，逐规格库存预警；默认低于2件提示，阈值可修改。
- **交付时间**：顾客选择纽约门店当地期望时间，商家确认或调整后模拟发货/完成自提。
- **琴行服务**：门店联系与咨询、到店试琴预约、八类乐器养护指南；云端确认提醒由顾客主动授权。
- **商家管理**：维护商品、规格、图片、分类、门店资料、运费和预警阈值。

## 快速体验

1. 克隆项目：

   ```bash
   git clone https://github.com/diweiyin849-del/WeChat-Mini-Program-for-YDW-Music-Store.git
   ```

2. 在微信开发者工具中导入仓库根目录。项目配置已包含小程序目录及云函数目录；正式使用时请换成你有权限的 AppID。
3. 保持 `miniprogram/config.js` 中 `mode: 'demo'`，点击“编译”。无需支付商户号或密钥。
4. 商品页点击“查看费用”，选择配送或自提，填写信息并选择期望交付时间，再提交模拟订单和体验模拟付款。
5. “我的 → 我的模拟订单”查看、搜索和筛选订单；“演示商品管理 → 管理模拟订单”确认交付时间、模拟发货或完成自提。
6. 在商家管理“店铺”中修改运费及库存预警阈值。阈值填0关闭预警。

旧订单、商品修改和已扣库存会保留。“清除本机购物数据”删除购物数据及订单历史，但不会恢复已扣库存；补库存请在商品管理中编辑，不要直接删除交易存储键。

## 演示配送规则

| 地区/方式 | 普通乐器 | 钢琴或包含钢琴的清单 |
| --- | ---: | ---: |
| 纽约市 | ¥0 | ¥300 |
| 美国其他演示地区 | ¥100 | ¥300 |
| 美国以外其他可选地区 | ¥200 | ¥600 |
| 到店自提 | ¥0 | ¥0 |

以上为人民币演示价，后台可修改；同单钢琴运费只收一次，不叠加普通运费。

**地址选择器仍使用中国省/市/区县及行政编码**：原650000映射为美国，650500映射为纽约，其他合法地区按境外演示费用计算。未提供全球地址库、真实国际物流、清关或税费服务。预置型号、价格、图片、门店电话和地址均为演示资料，正式使用前需替换。

## 开发与验证

本地测试需要 Node.js 20或更高版本。根项目无第三方测试依赖。

```bash
npm test
npm run check
npm run package:cloud
node scripts/export-seed.js
```

当前119项自动测试通过，覆盖库存、运费、订单幂等、时间确认、权限、持久化和页面交互逻辑。静态检查与Node测试不代表微信原生渲染、真机或云部署验收。

`cloudfunctions/store/domain/` 与 `server/` 是生成副本，不提交到仓库。部署前先执行 `npm run package:cloud`，再按配置指南部署云函数、数据库规则及依赖。

## 项目结构

```text
miniprogram/    小程序页面、组件、业务逻辑与本地图片
server/        云函数服务端业务和权限逻辑
cloudfunctions/store/  云函数入口及依赖配置
cloud-seed/    演示数据库导入资料
scripts/       检查、云函数打包和种子导出脚本
tests/         自动测试
docs/          使用、部署与人工验收说明
```
